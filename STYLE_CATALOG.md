# Style Catalog — Every Available Design

The complete design library behind Frontend Slides: **12 curated presets + 34 bold
templates = 46 documented designs**, plus an unbounded custom (wildcard) slot where a
design is authored from scratch.

Phase 2 shows the user **3 previews**. That is a sampling step, not the size of the
library. Read this catalog when you need to widen the shortlist, when the user asks
"what else is there?", or when a sermon's register has no strong match in your first pass.

**This file is an index.** Do not read any `design.md` from here — follow the normal
progressive-disclosure rules in [SKILL.md](SKILL.md): `preview.md` for shortlisted
candidates, and exactly one `design.md` after the user chooses.

**Sermon fit** columns are graded for a preached worship service:

| Grade | Meaning |
| ----- | ------- |
| **Yes** | Safe default for a sermon; register suits worship |
| Situational | Works for a specific occasion listed in the row |
| Caution | Youth/kids/informal contexts only — not a main service |
| No | Register actively clashes with worship; do not offer for a sermon |

For how to *choose* among these from sermon content, see [SERMON_DESIGN.md](SERMON_DESIGN.md).

## Sermon-safe shortlist

When you need a dependable option fast, these are the designs graded **Yes** above:

- **Presets:** Dark Botanical, Notebook Tabs, Vintage Editorial, Swiss Modern, Paper & Ink
- **Bold templates:** Biennale Yellow, Bold Poster, Broadside, Cartesian, Cobalt Grid, Coral, Editorial Forest, Editorial Tri-Tone, Emerald Editorial, Grove, Long Table, Mat, Monochrome, Pin & Paper, Signal, Soft Editorial, Stencil & Tablet, Vellum

## Never offer for a worship service

Neon Cyber, Terminal Green, 8-Bit Orbit, Pink Script — After Hours, Retro Windows, Sakura Chroma.

These are excellent designs — they are simply the wrong register for preaching. They
remain fully available for any non-sermon deck built with this skill.
